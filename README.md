# 🍽️ BiteBook – Campus Smart Food Ordering System
BiteBook is a web-based food ordering platform designed for VIT Bhopal University students to streamline ordering from campus canteens like Underbelly and Mayuri. It eliminates long queues, chaotic ordering, and delays by providing a digital ordering solution with real-time tracking and scheduling.

## 🚀 Features
- 📋 Digital Menu System – View updated menus from multiple canteens
- 🛒 Cart System – Add/remove items before checkout
- 🕒 Order Scheduling – Place orders and choose pickup time
- 🔔 Order Tracking – View live status from preparation to pickup
- 💳 Secure Payments – Online payment options
- ⭐ Ratings & Feedback – Users can review food items
- 🎯 User-Friendly Interface – Accessible on mobile, tablet & desktop
- 🧾 Order History – Track past purchases

## 🧠 Motivation
Students often face:
- Overcrowded canteens during breaks
- Long waiting times affecting classes
- Manual ordering & cash-only systems
- No feedback or transparency
BiteBook solves these issues using a scalable digital ecosystem.
